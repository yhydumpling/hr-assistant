# 外部系统接入

项目为招聘软件与企业微信预留适配器接口。考虑候选人资料的隐私风险，公开版本默认停用外部同步与通知，不配置访问凭证，也不会发送候选人数据。

## 接口边界

接口契约位于 `src/server/integrations/contracts.ts`，默认实现位于 `src/server/integrations/index.ts`。

| 系统 | 预留方法 | 输入范围 |
| --- | --- | --- |
| 招聘软件 | `syncApplication` | 应聘档案 ID、姓名、岗位、招聘阶段 |
| 企业微信 | `notifyInterview` | 应聘档案 ID、姓名、轮次、时间、地点与企业成员 ID |

默认适配器始终返回 `INTEGRATION_DISABLED`，不发起网络请求。接口尚未连接到具体厂商，修改 `enabled` 标记不会自动获得真实接入能力。

## 授权合作后的接入

取得合作方授权后，可沿上述接口实现厂商适配器，配置企业身份与凭证、字段映射和接收对象，再将已授权的同步或通知操作连接到招聘流程。接入时应明确允许传输的数据范围与触发条件；默认契约不包含简历原文、附件或密码。

实际使用仍需对接目标系统并完成联调。不同招聘软件的字段、认证和权限可能不同，预留接口不等于已完成所有厂商连接。

## 邮件草稿

对话中的面试邀请邮件与外部系统适配器分开处理。助手整理收件人、抄送、主题与正文；用户可以编辑，再交给自己的邮件客户端发送。生成草稿、登记面试均不代表邮件已经发送，公开版本没有后台 SMTP 发送服务。
