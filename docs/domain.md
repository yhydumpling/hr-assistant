# 领域词汇

面向 HR 的招聘资料与流程工作台。HR 用自然语言表达查询或操作，确认变更后推进应聘流程。

## Language

**候选人档案**：某位候选人应聘某一岗位的一份资料与流程记录。同一个人应聘不同岗位时，可以分别建立档案。
_Avoid_：将其称为全局人员身份或完整人才主数据。

**岗位**：招聘中的一个职位及其 JD、关键技能要求。

**简历提取字段**：从候选人提供的简历中整理出的基础资料，保留原文表达的事实范围。求职意向不等于现任职位，意向城市不等于现居城市。
_Avoid_：已认证资料、完整候选人画像。

**提取依据**：支持某个字段候选值的简历原文片段。它说明值从何而来，不证明简历内容真实。

**待核对字段**：存在多个候选值、表达含糊或需要人工确认的字段。HR 核对后可以选择、修改或留空。
_Avoid_：低能力、低匹配度。

**最高教育层次**：简历明确记载的最高教育层次，连同在读、预计毕业或肄业等状态。它不自动等同于已经获得的学位。

**工作年限**：简历明确陈述的累计工作年数。实习、项目或教育经历的时间跨度不自动计为工作年限。

**待确认操作**：根据 HR 的一句话整理出的流程变更，等待 HR 明确确认后才生效。
_Avoid_：已执行操作、自动决策。

**面试安排**：候选人的一场面试，包含轮次、日期、时间、面试官和地点。

**操作记录**：已生效的入库、阶段更新或面试安排记录。

**邀请邮件草稿**：面向候选人的面试邀请内容，包含收件人、抄送、主题和正文，供 HR 编辑后发送。
_Avoid_：已发送邮件、送达记录。

**外部系统接入**：在企业授权范围内，将招聘资料或通知与招聘软件、企业微信连接的协作能力。
_Avoid_：默认开启的数据同步、通用厂商即插即用。

**本地指令模式**：按预先定义的招聘语句和规则识别操作的模式，支持缺信息时继续补充。
_Avoid_：通用大模型、无限制自然语言理解。
